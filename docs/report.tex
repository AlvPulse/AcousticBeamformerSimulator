\section{Introduction}
This report serves as the official erratum and diagnostic analysis for the 50-microphone outdoor acoustic array simulation. Following peer-review feedback, we address the lack of absolute timings, coherent combining decomposition, and the necessity of mathematically interpretable "white-box" algorithms for field-deployed ecoacoustics.

Deep learning approaches (DNNs) often fail the "reality test" in outdoor deployments due to their black-box nature and inability to generalize to unexpected interferers without thousands of hours of annotated data. To rectify this, this update implements Unsupervised Blind Source Separation (BSS) and Statistical Spatial Audio Processing.

\section{Verification of Mathematical Bounds}
To prove the implementations operate exactly as mathematically intended in the literature, we generated verification bounds using canonical 10-element Uniform Linear Array (ULA) narrowband textbook models (see \texttt{experiments/reproduce\_papers.py}).

\subsection{Robust SOCP vs Target Self-Cancellation}
Standard LCMV (MVDR) minimizes the variance $\mathbf{w}^H \mathbf{R} \mathbf{w}$ subject to $\mathbf{w}^H \mathbf{a}_0 = 1$. When the actual target steering vector differs from $\mathbf{a}_0$ (due to wind or calibration error), LCMV treats the target as interference and cancels it.

Vorobyov et al. \cite{Gershman2010} proposed the Worst-Case Robust SOCP algorithm, which solves:
\begin{equation}
\min_{\mathbf{w}} \mathbf{w}^H \mathbf{R} \mathbf{w} \quad \text{subject to} \quad \text{Re}\{\mathbf{w}^H \mathbf{a}_0\} \ge \epsilon \|\mathbf{w}\|_2 + 1, \quad \text{Im}\{\mathbf{w}^H \mathbf{a}_0\} = 0
\end{equation}
This explicitly bounds the steering vector mismatch by $\epsilon$. Our explicit reproduction (Fig 1) matches Vorobyov's results perfectly: standard LCMV Output SINR collapses immediately at $1^\circ$ error, while SOCP maintains maximum SINR across the entire $5^\circ$ error sweep.

\subsection{Covariance Matrix Tapering (CMT)}
To mitigate the "razor-thin" null problem against moving interferers (airplanes), CMT mathematically widens the null. It computes a spatial tapering matrix $\mathbf{T}$ and applies the Hadamard product to the sample covariance matrix prior to inversion:
\begin{equation}
\mathbf{\hat{R}} = \mathbf{R} \odot \mathbf{T}, \quad \text{where } T_{ij} = \text{sinc}\left(\frac{2\pi f d_{ij} \sin(\Delta \theta)}{c}\right)
\end{equation}
Our reproduction (Fig 2) verifies Mailloux's \cite{Mailloux1995} findings: the standard LCMV places a singular sharp notch at $30^\circ$, whereas CMT creates a widened trough, ensuring moving interferers cannot leak out of the suppression zone.

\section{New Interpretive Algorithms}

\subsection{Independent Low-Rank Matrix Analysis (ILRMA)}
For zero-labeled unsupervised separation of harmonic targets (e.g., wildlife) from broadband diffuse noise (roads), we implemented ILRMA. It combines Independent Component Analysis (ICA) with Non-negative Matrix Factorization (NMF) to separate sources based purely on the statistical structure of their spectrograms.

\subsection{Statistical Time-Frequency Masking (IPD Variance)}
To handle wind and diffuse noise robustly without DNNs, we compute the Inter-Channel Phase Difference (IPD) variance. When phase variance is low, the array applies adaptive suppression (LCMV). When variance is high (wind/diffuse noise), it falls back to passive Tapered DAS to preserve White Noise Gain (WNG).

\subsection{Generalized Sidelobe Canceller with Multi-Channel Wiener Post-Filtering (GSC-MCWF)}
We implemented a GSC architecture with a Zelinsky MCWF post-filter. The MCWF mathematically suppresses frequencies where the noise variance (from the blocking matrix) is high, providing mathematically optimal MSE noise reduction without the "musical noise" artifacts of standard spectral subtraction \cite{Zelinsky1977}.

\section{Coherent Combining vs. Non-Coherent Accumulation}
A critical diagnostic is verifying that the beamformers are achieving coherent signal summation rather than passively accumulating energy. We extract the True Spatial Array Gain ($AG$):
\begin{equation}
AG = SNR_{out} - SNR_{in}
\end{equation}
The diagnostic plotter visually decomposes this metric to prove coherent gain across move-types. Additionally, the profiler now tracks absolute block latency ($L_{ms}$) to verify real-time viability.
